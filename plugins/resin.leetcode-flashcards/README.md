# 力扣速记卡

在岛仔状态页按专题浏览 Hot 100、记录 Markdown 解题思路并管理自选题。

## 启用

安装后在「设置 → 插件 → 已安装」启用。关闭或卸载后，岛上功能页与常驻状态会同步隐藏；内置 Hot 100 题库与本地保存的思路笔记、自选题均可离线使用。

- **浏览与记笔记**。左侧按专题切换题目，右侧查看题意、输入、输出、约束和样例。逐题保存 Markdown 思路，支持同屏预览和离线代码高亮。点「进入原题」可在浏览器打开力扣页面。
- **管理自选题**。点「自选题」右上角的「+ 添加 / 导入」，可分步填写题目，或粘贴单题 JSON。已添加的题目支持编辑和确认删除。
- **插件设置**。可选择默认题库、默认代码语言，以及切题时是否优先展开思路。岛上可常驻显示当前题目、思路摘要、刷题进度或已记思路轮播，也可关闭常驻。可单独开关番茄专注结束时的推题提醒。

## 来源与范围

默认题单按[力扣热题 100](https://leetcode.cn/studyplan/top-100-liked/)的 17 个专题排列，每题附原题链接与样例，题面为简明转述。
