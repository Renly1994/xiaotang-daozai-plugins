# 现货比特币测试

用启用了 `sdk-js` 的岛仔，在本目录执行以下命令。`$daozai` 指向验收版 `daozai.exe`。

```powershell
& $daozai --plugin-test "$PWD\plugin.json"
Get-ChildItem .\fixtures\*.json | ForEach-Object {
    & $daozai --plugin-test "$PWD\plugin.json" --input $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "验收失败：$($_.Name)" }
}
node --test fixtures/test.cjs
```

| 用例 | 预期 |
| --- | --- |
| `normal` | 大价格为 `60,348`（USDT 纯数字，无 `$`），区间高 `60,498 USDT`、区间低 `60,146 USDT`（取 K 线高低字段），常驻位 `60,348 USDT` |
| `stale` | 最后一根日线距今 2 天 + 1 小时，右下角橙色「旧行情 · 11.26」，状态标签「现货比特币（旧行情）」，常驻位撤下 |
| `stale-day` | 24小时视图最后一根 15 分钟线距今 1 小时，同样标旧行情并撤下常驻位 |
| `fx-stale` | 汇率源缺失但缓存（7.2）在 2 天有效期内：大价格 `≈¥` 折算值，提示「汇率待更新，按缓存汇率估算」，常驻位退回 `60,348 USDT` |
| `fx-expired` | 缓存汇率超过 2 天：整体退回 USDT，提示「汇率待更新，已按 USDT 显示」 |
| `cny` | 汇率新鲜：大价格 `≈¥437,259`，提示「人民币为汇率折算，估算值」，常驻位 `≈¥437,259` |

`fixtures/test.cjs` 用 `vm` 加载 `main.js`，覆盖 USDT 计价标注、区间高低取 K 线高低字段、旧行情阈值（日线收盘 +24h、15 分钟线收盘 +45min）、旧行情撤下常驻位、汇率缓存两级降级、CNY 估算口径与切换记忆。`--plugin-test` 只调 `refresh`，页面动作由测试脚本直接调用。

夹具数据为确定性合成：日线收盘 `60000+i×12`（最高 +150、最低 -130），15 分钟线收盘 `60000+j×13`（最高 +30、最低 -25），基准时刻 `now = 1795747200000`（2026-11-27 08:00 +08:00），汇率 7.2456。

口径说明：币安 `BTCUSDT` 原始报价为 USDT；人民币按腾讯 USDCNY 汇率折算（USDT≈USD），页面与常驻位标注为估算。旧行情按最后一根 K 线收盘时刻（开盘 + 周期）判断：15 分钟线容忍 45 分钟，日线容忍收盘后 24 小时。汇率源缺失时缓存汇率最多再用 2 天，过期退回 USDT；缓存期内状态页继续折算并提示估算，常驻位直接退回 USDT。
