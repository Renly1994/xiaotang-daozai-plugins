# 日子验收

在插件仓根目录运行以下命令。固定时间场景使用北京时间，`$island` 指向支持插件 SDK 的 `daozai.exe`。

```powershell
$plugin = 'plugins/daozai.days'
foreach ($case in Get-ChildItem "$plugin/fixtures/*.json") {
    & $island --plugin-test "$plugin/plugin.json" --input $case.FullName | Out-Host
    if ($LASTEXITCODE -ne 0) { throw "$($case.Name) 校验失败" }
}
node --test "$plugin/fixtures/test.mjs"
```

| 模拟输入 | 预期输出 |
| --- | --- |
| `design.json` | 普通日展开元旦倒数 38 天，右侧车票混排节假日、生日和纪念日。 |
| `ordinary.json` | 我的日子显示聚餐还有 1 天，列表按日期合并自己的日子和节假日，次日午夜刷新。 |
| `holiday.json` | 国庆节显示「今天」，日历标注「国庆节 · 休」。 |
| `own-only.json` | 节假日关闭，列表只显示两项自己的日子。 |
| `makeup.json` | 我的日子提示调休上班，日历标注「班」。 |
| `anniversary.json` | 常驻显示「开工纪念·100天·2026-08-16·星期日」，通知「开工纪念已满 100 天」。 |
| `leap-birthday.json` | 平年的闰日生日在 2 月 28 日显示「今天」并提醒。 |
| `leap-year.json` | 闰年 2 月 28 日显示生日还有 1 天。 |
| `filtered.json` | 从私有存储恢复节假日筛选。 |
| `reminder-queue.json` | 首次发一条生日通知，61 秒后安排同日的下一条提醒。 |

逻辑测试覆盖筛选和点车票常驻、长名称的常驻倒数、午夜撕页、待公布的次年数据、重排后的提醒去重和发送间隔，以及 20 条日子、每月和每年重复、图标与颜色。

「我的日子」集中保存最多 20 项。名称最多取 12 字，常驻模板最多取 24 字。表单初始的旗子和红色组合按类型显示，生日默认蛋糕、橙色，纪念日默认爱心、紫色。「重复」可选默认、每月或每年。默认每年计算生日，其他日子只计算一次。每月重复沿用原日期的日号，短月取月末，下月恢复原日号。

点车票可选择常驻条，也可以在设置中填写日子名称。点「恢复最近」后，同一位置显示「常驻跟随最近」，即使当前筛选隐藏了最近的车票，仍能确认切换成功。设置页目前使用名称输入，宿主的下拉选项来自清单中的固定列表。

从旧版分组设置升级时，可先导出或复制分组中的日子设置，再填入新的「我的日子」列表。新列表的字段由宿主按新版完整校验。

2027 年节假日按国务院办公厅已发布的通知，春节假期为 2 月 5 日至 13 日。 [2027 年部分节假日安排](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)
