# 虹彩光浪

在「外观」换上收起静态浅黑、展开顶部黑透与居中全宽流光材质。收起时保持纯粹静态浅黑色，展开后顶部黑曜石在约 4/5 处向透明折射玻璃渐变，正中悬浮随动态演进的双层白芯冰青琥珀光浪，外围采用极细冷暖色散晶边。

安装后在「设置 → 插件 → 已安装」启用，首次启用需确认 `screen.backdrop` 权限并开启「兼容渲染（Direct3D 12）」，建议搭配深色基础皮肤（默认「经典」或「深色毛玻璃」）保持浅色文字对比。注意：材质生效期间主岛会自动从常规截图和录屏中隐藏，停用或卸载后会恢复用户原来的截图隐藏设置，原有皮肤与外观也会一并恢复；可在「设置 → 外观 → 材质」调节黑透分界位置、折射、弧光亮度与动态流速等 12 项参数，插件完全离线运行。

备注：视觉表现仿 Siri-AI 动效风格（仅作外观参考，非官方出品）。本插件的光学框架、控件命中与十字采样骨架（`hash21`、`rounded_normal`、`corner_weight`、`pick_control`、`control_glass` 等）改编自岛仔官方「液态玻璃」样例（作者 @cayww）；在此基础上原创编写了黑曜石至透明玻璃的分段渐变、`DockSpace` 四方向坐标统一映射、收起静态浅黑早退分支、居中全宽双弧动态光浪与极细冷暖色散晶边算法及插件封面，按岛仔 GPU 材质接口 `api: 1` 制作（MIT 许可，见 `LICENSE`）。材质仅在本机 GPU 实时采样岛体背后画面用于渲染，不保存不上传，无网络和本地文件读写权限。
