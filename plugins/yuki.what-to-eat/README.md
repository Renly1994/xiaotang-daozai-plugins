# 今天吃什么（yuki.what-to-eat）

不知道今天吃什么？那我来帮你选吧。

一个独立状态页插件：点「开始」从菜谱库里随机帮你抽一顿饭，不满意就「换一个」，抽中还会给一条搭配小贴士。

## 功能

- **随机抽签**：内置 141 道常见菜，随机推荐不连续重复
- **属性标签**：每道菜带分类、荤素、辣度标签，紧跟菜名右侧显示
- **筛选条件**（插件设置）：
  - 类型：全部 / 家常菜 / 米饭面食 / 早餐 / 快餐外卖 / 地方风味
  - 荤素偏好：荤素不忌 / 偏爱荤 / 偏爱素
  - 辣度：辣度随意 / 微辣可以 / 不吃辣
  - 私房菜：可添加最多 20 道自己的菜，不受筛选限制，一定参与抽签
- **分时段问候**：早上、午饭、晚饭、夜宵各有开场白
- **智能兜底**：筛选条件太严没有可选菜时，自动放宽条件并提示
- **紧凑卡片**：自绘布局跟随岛仔皮肤令牌（$accent/$text/$track），高度约 126px，与原生状态页一致

## 使用

1. 「设置 → 插件 → 开发者工具」安装本目录的 `plugin.json` 并启用
2. 「设置 → 页面管理 → 状态详情」打开「今天吃什么」页面
3. 展开岛仔翻到该页，点「开始」抽一顿

## 数据与权限

- 不申请任何敏感权限（`permissions: {}`），不读文件、不访问网络
- 唯一存储是上次抽中的菜名（用于避免连续重复），可从「已安装 → ···」导出/导入
