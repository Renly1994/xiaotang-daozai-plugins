# 热点速览

在岛仔的独立状态页里看全网热点：两路可自选的今日热榜频道，加一路立创开源硬件项目。顶部是一块跟随皮肤的小型概览画布，下面是可点击的原生列表，8 条一页，共 24 条分三页。

## 功能

- **两路自选频道**：微博热搜、知乎热榜、百度实时热点、36氪热榜、哔哩哔哩日榜、微信热文，任选两个组合
- **立创开源硬件**：展示热门开源硬件项目，可在设置中关闭
- **三页列表**：每页 8 条，底部「上一页 / 下一页」循环翻页，共 24 条
- **概览画布**：显示每路来源的条数，颜色全部使用宿主主题令牌（`$card`、`$track`、`$accent`、`$text`、`$muted`、`$dim`），换皮肤自动跟随
- **每日精选**：每天首次刷新时推一条一次性提醒，内容为当日三条热点，可在设置中关闭
- **15 分钟定时刷新**，榜单按来源交错排列，避免某一页只有一个来源

## 设置项

| 设置 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| 第一路频道 | choice | 微博热搜 | 六选一 |
| 第二路频道 | choice | 36氪热榜 | 六选一 |
| 立创开源硬件 | choice | 显示 | 显示 / 隐藏 |
| 每日精选推送 | choice | 推送 | 推送 / 不推送 |

## 数据与权限

- 权限：`source.read: "https"`，仅读取公开榜单，不发送任何用户数据
- 域名白名单：`tophub.today`（两路榜单）、`oshwhub.com`（开源硬件）
- 不读取本地文件，不申请 `file.read`，不需要账号或凭据
- 榜单页面在本地用正则解析，脚本不保存任何个人信息；`storage` 只保留条目列表、页码和当天推送标记

## 打开链接的说明

SDK 只允许打开清单白名单内的域名，因此：

- 热榜条目点击后打开**对应的榜单页**，在榜单页里可继续跳到原文
- 立创开源条目点击后**直接打开项目原文**（`oshwhub.com` 在白名单内）

## 本地试装

岛仔 v0.6.70 或更新版本：

1. 「设置 → 插件 → 已安装 → 开发者工具 → 安装本地插件…」，选择本目录的 `plugin.json`
2. 回到「已安装」启用插件，在「设置 → 页面管理 → 状态详情」打开「热点速览」
3. 在插件设置里切换两个频道，或关闭立创硬件，核对列表变化

命令行校验：

```powershell
& 'D:/你的目录/daozai.exe' --plugin-test ./plugin.json --input ./fixtures/mock.json
```

详见 [TESTING.md](TESTING.md)。
