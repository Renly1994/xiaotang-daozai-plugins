# 实时工资

在状态详情看今天已赚的工资、下班倒计时和发薪日。可设置工作日、上下班时间及最多四段休息，每段独立选择是否计薪。

安装后在「设置 → 插件 → 已安装」启用。在「状态详情」填写月薪和作息，在「岛上常驻」选择实时工资。到下班时间会收到一次「下班啦」提醒。停用或卸载后，详情和常驻会移除。

工资金额按月薪、计薪周期内的工作日数及班次计薪时间估算。默认按自然月。选择自定义后，设置每月的起止日，例如 16 日至次月 15 日。含起止当天，超出短月的日期按月末，两期重合日归下一期。周期外的班次计薪为零，跨午夜的班次按上班日认定。

每月发薪日设为 1 至 31。短月按月末，发薪当天显示「今天发薪」，设置为 0 时关闭倒计时。也可把「常驻显示」切到「发薪倒计时」。插件可离线使用。
