# 透明标

让岛体背景透明，显示时间、图标和控件。

安装后在「设置 → 插件 → 已安装」找到「透明标」，从「设置 → 外观 → 材质」选用它。首次启用时按岛仔提示确认屏幕底片权限。材质需要 Windows 版岛仔的 Direct3D 12 兼容渲染。要恢复原主题，可在「材质」切回默认。

适用于支持 GPU 材质的岛仔。本地校验版本为 v0.6.70。材质的背景 alpha 和岛体投影强度均为零。展开后，控件和卡片由宿主按玻璃前景样式绘制。材质申请宿主的屏幕底片权限，着色器本身未采样屏幕纹理，插件可以离线使用。材质生效时，岛仔按宿主规则将主岛排除在常规截图和录屏之外。封面为原创示意图。
