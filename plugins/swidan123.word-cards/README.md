# 随手背词

在状态页和顶部常驻胶囊里随时背单词。集成艾宾浩斯遗忘曲线调度、闪卡 / 四选一 / 键盘拼写三种练习模式、错词攻坚本、自建生词本，以及番茄专注结束自动推词提醒。

## 启用

安装后在「设置 → 插件 → 已安装」启用，可在设置中配置默认词书、默认练习模式、每日目标词数、顶部常驻样式、朗读口音、番茄专注推词开关与自建生词本。停用或卸载后移除对应状态页和常驻条；背词可离线使用，点击「朗读」需要联网。

## 来源与范围

内置雅思/考研高频、四六级核心、科研/程序员英语三套精选离线词表（含音标、释义与例句），不读取本机文件，不主动发起后台网络请求。用户主动点击「朗读」按钮时，会将当前单词（包括自建词）通过浏览器打开 `dict.youdao.com` 获取发音。
