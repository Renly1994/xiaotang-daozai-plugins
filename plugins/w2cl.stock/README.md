# 自选股

在状态页查看上证指数和两只自选股的现价、分时，并设置价格提醒、止盈和止损。

安装后在「设置 → 插件 → 已安装」启用。在插件设置里填写自选代码；价格提醒和止盈止损分成两个列表。停用或卸载后，详情、常驻和提醒会撤下。行情需要联网。

## 更新说明

从 1.0.0 更新到 1.0.1 后，原有价格提醒会保留，到价后仍会提醒。止盈和止损改在新的「止盈止损」列表里单独填写。

行情地址已改为 HTTPS。更新后请在「设置 → 插件 → 已安装」中重新授权腾讯行情数据源，否则页面会停在「等待授权」。

## 来源与范围

行情来自腾讯行情，只读访问 `qt.gtimg.cn`、`ifzq.gtimg.cn`、`web.ifzq.gtimg.cn` 和 `gu.qq.com`。代码用小写前缀，如 `sh600519`、`sz000001`。
