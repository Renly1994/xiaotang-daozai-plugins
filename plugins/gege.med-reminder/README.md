# 吃药提醒

在状态页记录每天要吃的药和提醒时间，到点提醒，点一下就能记下已吃。

## 用途

在状态页按点提醒吃药，并记下今天哪一次已经吃过。

- 列表每行是一味药：药品名称、每次数量、每天的所有提醒时间
- 点某一行里的时间气泡，就在「已吃 / 未吃」之间切换，吃过的会加粗点亮
- 点行尾的 × 会进入二次确认：行内变成红圈白叉，页面底部出现「取消」「确认删除」，不会误删
- 一味药可以加多个时间；列表超过 3 味时右侧出现上下箭头和位置指示条，按「上一味 / 下一味」翻看
- 岛仔收起时常驻显示下一次要吃的药：药名 + 数量 + 时间

## 启用

安装后在「设置 → 插件 → 已安装」启用，再在「设置 → 页面管理 → 状态详情」打开「吃药提醒」页面。

到点后在「提醒容错（分钟）」窗口内提醒一次，同一天同一时段只提醒一次；窗口默认 10 分钟，可在「设置 → 吃药提醒」调整为 1～120 分钟。

停用或卸载后，岛仔不再提醒，已填的药单仍保留在插件数据里，重新启用即可继续用。插件完全离线运行，不需要网络。

## 来源与范围

- 不读取网络、不读取本机文件，不申请任何外部权限
- 药品名称、数量、提醒时间和「已吃」记录只写在本机该插件的私有存储中，不上传
- 提醒通过岛仔的通知接口推送，声音由系统通知自身提供
