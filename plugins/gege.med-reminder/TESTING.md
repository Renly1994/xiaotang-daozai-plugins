# 试装与本地校验

## 试装步骤

1. 岛仔打开「设置 → 插件 → 已安装 → 开发者工具」，点「安装本地插件…」，选择本目录的 `plugin.json`
2. 回到「已安装」启用「吃药提醒」
3. 在「设置 → 页面管理 → 状态详情」打开「吃药提醒」页面
4. 填药品名称和数量，用 ◀ ▶ 调好时分，点「加入」把时间存进列表，再点「保存」
5. 点列表里的时间气泡，确认能在「已吃 / 未吃」之间切换
6. 点行尾 × 进入删除确认，再在页面底部点「取消」，确认药没有被删掉
7. 再点 × 并在底部点「确认删除」，确认该味药从列表移除

## 本地校验

```powershell
$island = '你的岛仔目录\daozai.exe'
& $island --plugin-test .\plugin.json
$LASTEXITCODE
```

结果：返回码 `0`，输出 `gege.med-reminder v1.0.0 校验通过`。

另外用一份 Node.js 回归脚本核对了 21 项状态逻辑、17 项删除确认流程和 8 项滚动条显示规则，全部通过：

- 列表与药单在 1～24 味之间不串行，时间气泡命中当前行
- 删除需两次确认，确认态高度与原生按钮位置正确，取消不删除
- 3 味以内不绘制滚动条与上下箭头，4 味以上才出现
