# 功德木鱼

在状态页敲击木鱼累积功德，连击可升至两倍和四倍。

## 界面与交互

- 点击木鱼（或棒槌）敲一下，棒槌落下后自动抬回，木鱼轻微下沉
- 右侧显示累计功德；连击期间数字变绿，翻倍时变金，停手后自动恢复白色
- 连击达到设定档位时，木鱼外圈出现金色光环：一档单层、二档双层
- 停手超过宽限时间后，按设定周期扣除功德；此时数字下方显示红字，例如「超时20分钟 · 功德 -10」
- 扣分从**第一次敲击**开始计时：从未敲过时不会扣分；重置后同样要等下一次敲击才重新开始计时
- 连击光环与数字颜色同步：停手超过连击间隔，光环和数字一起恢复，无需再次敲击
- 累计功德右下角的重置图标单击一次即可清零累计功德与连击，无二次确认

## 设置项

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 功德名称 | 显示在画布上的名称 | 功德 |
| 每次敲击功德 | 每次敲击增加的基础值 | 1 下 |
| 每档需要连续多少下 | 达到 N 下进入一档（×2），2N 下进入二档（×4），封顶二档 | 20 下 |
| 连击间隔上限（超过则回到 1 倍） | 相邻两次敲击超过此间隔，连击直接回到 ×1，不降档 | 1 秒 |
| 停手多久开始扣功德 | 宽限时间，超过后才开始扣 | 30 分钟 |
| 超时后每多久扣一次 | 扣除周期 | 2 分钟 |
| 每次扣多少功德 | 每个扣除周期扣掉的值，累计可为负 | 1 下 |
| 扣功德生效时段·开始 / 结束 | 只有落在此时段内的空档才计时扣款，支持跨夜 | 08:00 / 19:00 |

## 自测用例（0.6.70）

1. **敲击**：点木鱼，棒槌落下后自动抬回；连敲 20 下进入一档（每下 ×2），40 下进入二档（×4）
2. **断连**：到 ×2 或 ×4 后停手超过连击间隔，数字与金色光环同时恢复，不用再敲
3. **重置**：点累计功德右下角的重置图标，累计功德与连击都归零
4. **扣分起点**：生效时段内启用后一直不敲，累计保持 0；敲一下后停手 32 分钟（默认宽限 30 分钟、每 2 分钟扣 1），累计变为 −1
5. **超时提示**：此时数字下方出现红字「超时2分钟 · 功德 -1」
6. **跨夜扣分**：生效时段设为 22:00–06:00，跨夜停手只统计时段内的时长
