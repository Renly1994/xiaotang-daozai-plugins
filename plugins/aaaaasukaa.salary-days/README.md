# 欠薪第几天

在岛仔的**独立功能页**（设置 → 页面管理 → 插件页面）查看距离最后一笔已结清工资到账已经过去多久。

页面版式照原生页来：左上「欠薪 + 第几天」，右上当天日期与时间，中间大字「N 天 HH:mm:ss」实时走秒，下面「≈ K 个月 · 起算 …」，底部三颗按钮 **记 1 个月 / 记 3 个月 / 记 6 个月**。发了工资就按一下，起算点按自然月顺延，天数重新计算；月末按目标月最后一天裁剪，例如 1 月 31 日加 1 个月记为 2 月 28 日。

- 起算日是最后一笔已结清工资的到账日，不是应发日。
- 时间按本地时区计算，关机或睡眠期间照常累计。
- 「第 N 天」由岛仔本地每秒递增，零点和时钟一起翻。
- 秒是把时区按起算时刻平移后交给画布的时钟绑定，所以能逐秒显示「HH:mm:ss」，不是静态文字。
- 月薪填 0 表示只计时、不显示金额。
- 已发月数存在插件自己的记录里，卸载选「保留数据」再装回不会丢。

## 启用

安装后在「设置 → 插件 → 已安装」启用插件，再到「设置 → 页面管理 → 插件页面」确认「欠薪第几天」这一页是开的。插件不联网，数据只存在本机。

## 来源与范围

欠薪天数、月数与金额全部由本地日期计算，不读取任何账号、工资条或邮件。支持 Windows 版岛仔的独立状态页，刷新间隔 60 秒。代码以 MIT 许可分发。
