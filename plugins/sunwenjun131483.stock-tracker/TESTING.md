# 自选股盯盘测试

用启用了 `sdk-js` 的岛仔，在本目录执行以下命令。`$daozai` 指向验收版 `daozai.exe`。

```powershell
& $daozai --plugin-test "$PWD\plugin.json"
Get-ChildItem .\fixtures\*.json | ForEach-Object {
    & $daozai --plugin-test "$PWD\plugin.json" --input $_.FullName
    if ($LASTEXITCODE -ne 0) { throw "验收失败：$($_.Name)" }
}
```

| 用例 | 预期 |
| --- | --- |
| `mock` | 茅台现价 `1688.00`，`+13.00 · +0.78%`，持仓 `成本 1600.00 · 100 股`，盈亏 `+8,800.00`；平安银行 `11.85`，`-0.15 · -1.25%`，持仓 `成本 12.00 · 1000 股`，盈亏 `-150.00` |
| `profit-off` | 「显示浮动盈亏」为 `false` 时，两只持仓只显示成本与股数，不出现盈亏金额 |
| `empty-change` | 涨跌额与幅度留空时，按现价 `1688.00`、昨收 `1675.00` 推算 `+13.00 · +0.78%`；真实零值仍按零显示 |
| `cached` | 三路离线但有本地缓存时，卡片显示「上次报价 15:30」，行情与常驻条按旧价淡化着色，不作实时涨跌强调 |
| `offline` | 三路均离线且无缓存，画布显示「还没有可用的股票」，常驻为空 |

在「设置 → 插件 → 已安装 → 开发者工具」选 `plugin.json` 试装。启用并授权 HTTPS 数据源后，切到自选股盯盘状态页。用页面「刷新」按钮手动取数；在插件设置调整代码、成本价、持股数量、配色和盈亏显示。个别来源掉线时沿用上次报价并标注「上次报价」；全部来源离线时由宿主决定是否展示缓存画面。
