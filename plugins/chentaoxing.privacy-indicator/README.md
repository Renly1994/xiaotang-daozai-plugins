# 隐私指示

在状态页查看摄像头和麦克风正在被哪些程序使用。

## 启用

安装后在「设置 → 插件 → 已安装」启用，再在插件详情点「授权数据源」，选择本机读数程序写出的文件：

`%LOCALAPPDATA%\IslandPrivacy\devices.json`

未授权、文件不可用或内容损坏时，状态页显示「未获得系统占用状态」，不会把读不到当成未被占用。

- **展开岛主页（状态页）**：每个被占用且对应开关开着的设备各显示一个高反差圆形亮块，做 `pulse` 真闪烁，并列出占用程序；摄像头和麦克风同时占用时上下两行同时闪烁。
- **收起态（灵动岛胶囊）**：显示彩色圆点和滚动文字。单设备显示「摄像头正在使用 · 程序名」或「麦克风正在使用 · 程序名」；双设备时左右两半分别显示，摄像头为红色、麦克风为绿色，文字与各自圆点同色。
- 插件设置页有「摄像头爆闪」「麦克风爆闪」两个独立开关，默认都开。关闭某设备后，该设备占用时只显示普通文字，不再闪烁。
- 需要收起时也显示，请在插件设置页打开「在岛上常驻显示」，再到「设置 → 页面管理 → 岛上显示」调整顺序。
- 停用或卸载会立即撤下常驻位与状态页。本插件不联网，可完全离线使用。

## 读数程序

当前岛仔宿主还没有摄像头／麦克风占用数据源，插件因此读取一个本机读数程序写出的文件。程序只读当前用户自己的 Windows 占用账本，不打开设备、不录音录像、不联网。

集市插件包不能携带 `.exe`，所以桥接程序不随插件包分发；源码已随投稿放在仓库的 `fixtures/device-use/`，采用 MIT 许可。安装 Rust 后可在该目录编译：

```powershell
rustc --edition 2021 main.rs -o device_use.exe
.\device_use.exe --watch 2
```

`--watch 2` 每 2 秒刷新一次数据文件；按 `Ctrl+C` 停止。需要开机常驻时，可由你主动执行：

```powershell
.\device_use.exe --install-startup
.\device_use.exe --uninstall-startup
```

自启只写当前用户的注册表 Run 项，本插件不会替你静默安装。程序没在运行时，插件如实显示未知态。

## 已知限制

- **首次检测到占用最多等 60 秒**：岛仔后台刷新下限为 60 秒，动画本身在检测到后立即播放。秒级原生告警需要宿主开放 `device.use` 事件，提案见 [xiaotang-daozai#343](https://github.com/Renly1994/xiaotang-daozai/issues/343)。
- 当前只承诺 Windows 10／11；其他系统或读不到账本时显示「未获得系统占用状态」。

## 来源与范围

- **数据来源**：读数程序读取当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\webcam` 与 `...\microphone`，写成 UTF-8 JSON；你在岛仔里授权该文件后，插件通过 `input.source` 读取。
- **读取字段**：`camera`、`microphone` 两个数组，元素为 `{"name":"程序名"}`；`updated_at` 是读数程序的 Unix 秒时间戳。只保存上次占用程序名用于提醒去重，不保存图像、音频或历史时间线。
- **占用判定**：`LastUsedTimeStart > 0` 且 `LastUsedTimeStop == 0`。打包应用取包家族名，非打包应用取可执行文件名，排序并去重。
- **硬件无关**：读取的是应用占用桶，不依赖摄像头或麦克风的品牌、型号、设备名。
- **不读取**：不读文件内容、账号、浏览记录，不发网络请求，不打开摄像头或麦克风。
- **第三方许可**：插件与读数程序均为 MIT 许可；读数程序为独立实现，未使用第三方项目代码。
